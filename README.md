# UK Energy Price Service

## 🌙 Night Build Project

### 产品概念
帮英国家庭和小企业主监控能源价格,自动提醒最佳换供应商时机

### 功能
1. 每周自动获取能源价格
2. 当价格下降时自动Email提醒
3. 对比历史价格趋势
4. **NEW: 家庭住宅能源对比**

---

## 🏠 住宅能源 (Residential)

### 适用客户
- 英国家庭 homeowners
- 租房 tenants
- 房东 buy-to-let

### 用户输入
- 电费年度用量 (kWh)
- 燃气年度用量 (kWh)
- 当前供应商
- 付款方式 (direct debit / prepayment / credit)

### 比较项目
- 固定价格 vs 浮动价格
- 各供应商比价
- 推荐最优惠套餐
- 预计年省金额

### 用户数据示例
- 电: 46,677 kWh/年
- 燃气: 81,758 kWh/年
